# 🏎️ Formula 1 Analytics Dashboard | Power BI

## 📌 Project Overview

An interactive Formula 1 analytics dashboard developed using Microsoft Power BI to analyse driver and constructor performance across the 2010–2026 seasons.

The project uses data analysis, data modelling, and DAX (Data Analysis Expressions) to transform Formula 1 racing data into meaningful insights.

## 🎯 Project Objectives

- Analyse Formula 1 driver performance.
- Compare constructor performance across seasons.
- Track driver championship standings.
- Analyse points, wins, and podiums.
- Identify performance trends across seasons.

## 🛠️ Tools & Technologies

- Microsoft Power BI
- DAX (Data Analysis Expressions)
- Microsoft Excel
- CSV Dataset
- Data Cleaning and Transformation
- Data Visualization

## 📊 Dashboard Features

- Driver performance analysis
- Driver championship standings
- Constructor performance comparison
- Season-wise analysis
- Interactive filters and slicers
- KPI cards and charts

## 🧮 DAX & Data Modelling

DAX measures were used to calculate key performance indicators and support interactive analysis.
